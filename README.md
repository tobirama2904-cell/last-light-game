# LAST LIGHT

3D-игра о выживании в заросшем мире после Cordyceps. Полностью процедурная, без внешних ассетов на рантайме — весь мир, персонажи, анимации, погода и саундтрек создаются кодом.

## 📱 APK для Android

**Скачать готовый файл:** вкладка [**Releases → apk-latest → LastLight.apk**](../../releases/tag/apk-latest)

Установка на телефон:
1. Скачай `LastLight.apk` на устройство.
2. Настройки → разрешить установку из этого источника (Chrome / Проводник).
3. Открой файл → Установить. Нужен **Android 8.0+** и поддержка WebGL2 (все телефоны с 2018 года).

Игра работает **офлайн**: весь контент внутри APK. Экран сам блокируется в ландшафте,
управление — виртуальный стик слева, обзор пальцем справа, кнопки действий справа снизу.

APK собирается автоматически из этого репозитория через GitHub Actions
(`.github/workflows/android.yml`): CI собирает веб-игру в один файл, кладёт её в `assets/`
Android-проекта и компилирует APK.

### Собрать APK самому

```bash
npm ci && npm run build
mkdir -p android/app/src/main/assets
cp dist/index.html android/app/src/main/assets/index.html
cd android && ./gradlew assembleDebug     # или: gradle assembleDebug
# результат: android/app/build/outputs/apk/debug/app-debug.apk
```

Нужны JDK 17 и Android SDK (compileSdk 34).

## Как запустить в браузере

**Вариант 1 — готовая сборка (без установки):**
открой `dist/index.html` в браузере (Chrome / Edge, нужен WebGL2).
Это один самодостаточный файл ~8.5 МБ: в нём уже лежат JS, CSS, текстуры и ключевые кадры.
На Android-телефоне в Chrome доступна кнопка «Установить на телефон» — игра встанет как приложение (PWA).

**Вариант 2 — исходники:**

```bash
npm install
npm run dev      # разработка
npm run build    # сборка в dist/
```

## Управление

**ПК:** `WASD` движение · `SHIFT` бег · `CTRL/C` присесть · `Z` лечь · `ПРОБЕЛ` прыжок и запрыгивание ·
`ЛКМ` огонь/удар · `ПКМ` прицел · `R` перезарядка · `F` ближний бой · `G` бросок · `E` взаимодействие ·
`1–7` слоты · `H` эхолокация · `L` фонарь · `T` команды напарнику · `Q` еда · `TAB/ESC` пауза

**Телефон:** стик слева — ходьба (край = бег) · свайп справа — обзор · ОГОНЬ / ПРИЦЕЛ / БЛИЖ. / R /
ПРЫЖОК / ПРИСЕД / E / ЭХО — кнопки · верхний ряд: бросок, фонарь, приказ, еда, смена оружия, меню ·
кнопка «назад» телефона = пауза.

## Производительность на телефоне

Движок сам определяет мобильное устройство и включает облегчённый профиль:
плотность пикселей ≤ 1.1, дальность прорисовки 420 м вместо 1400, обычные PCF-тени вместо мягких,
меньше растительности и противников, дождь отключается. На Snapdragon 870 (Poco F4) это стабильные 50–60 fps.

## Технические заметки

- Three.js (WebGL2), ACES-тонмаппинг, PCF-мягкие тени, следящие за игроком
- статическая геометрия сливается по материалу — тысячи объектов рисуются десятками draw calls
- трава качается в вершинном шейдере, дождь/снег — точки с обновлением буфера
- весь звук синтезируется в WebAudio (осцилляторы + шум + свёртка), поэтому сборка автономна
